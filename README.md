# Trame releases

Signed and notarized builds of Trame, a frameless macOS web browser. The source code is private.

## Install

1. Requires a Mac with Apple Silicon and macOS 26.
2. Download `Trame.zip` from the [latest release](https://github.com/jbrnzl/trame-releases/releases/latest), unzip it and move `Trame.app` to Applications.
3. Open it. Updates install by themselves after that.
